# 에르하임: 사자의 맹세

쿼터뷰 자동사냥 3D MMORPG(오리지널). `index.html` 을 크롬에서 더블클릭해 열면 된다(서버 불필요, 1920×1080 기준, 창 크기에 맞춰 축소).

- 타이틀에서 **게임 시작** 또는 **녹화용 자동 모드**(마을 → 자동사냥 → 레벨업 → 강화 → 레이드, 약 3분)
- **게임 시작 → 회원가입/로그인**: 계정을 만들면 Lv.1 캐릭터로 시작하고, 진행 상황(레벨·금화·장비 강화·이야기 진행)이 계정별로 5초마다 자동 저장된다. 계정은 브라우저의 IndexedDB(`erheim_db`)에 저장되며 비밀번호는 PBKDF2-SHA256 값만 보관한다. 서버가 없으므로 같은 기기·같은 브라우저에서만 이어 할 수 있다. "계정 없이 체험하기"는 Lv.14 체험 캐릭터(저장 안 됨).
- **이야기 〈사자의 맹세〉** 서장 + 3막 18장 + 종장: 의뢰창의 [이야기]를 누르면 인물을 찾아가 대화하고 사냥·강화·성문 방어전·이름 있는 정예·레이드를 자동으로 진행한다. 컷신과 선택지 8곳이 있다. 대본은 `game/src/game/saga.js`(원본 `_work/v3/story_final.json`), 엔진은 `sagaengine.js`. 예전 저장본은 새 서장부터 다시 시작한다(레벨·장비는 유지).
- 주소 뒤에 `?demo=1` 을 붙이면 바로 자동 모드, `?play=1` 이면 바로 플레이(체험 캐릭터), `?play=1&story=1` 이면 저장 없는 Lv.1 이야기 모드
- 조작: 땅 클릭/WASD 이동, 몬스터 클릭·Space 공격, 1~0 기술, E 전문화 기술, T 귀환, R 자동사냥, Q·F1 빨간 물약, F2 파란 물약, I 가방, C 장비, B 레이드 소환, 대장장이 클릭 = 강화, 잡화상인 리나 클릭 = 상점
- **기술 체계**(`game/src/game/skills.js`): 레벨에 따라 기술 12종을 익힌다. 내력과 **투지**(공격·피격으로 쌓임) 두 자원, 공용 재사용 대기 1초, 발동 효과 2종, 정예·습격자·보스의 **시전을 뇌전검으로 차단**. Lv.10 에 전문화(수호·격노·서약) 하나를 고르면 전용 기술이 생긴다.
- **AI 플레이어를 DGX Spark 에서 구동**(선택): Spark 에서 `python3 spark/brain_server.py --host 0.0.0.0 --port 8787 --game .` 을 띄우고 같은 네트워크에서 `http://<Spark 주소>:8787/` 로 접속하면 AI 플레이어의 이동·공격·대사를 Spark 가 정한다(LLM 은 목표와 대사, 매 틱 움직임은 정책 코드). 서버가 없거나 끊기면 브라우저 내장 AI 로 돈다. https 사이트(GitHub Pages)에서는 http 서버에 붙을 수 없어 내장 AI 로만 돈다. 자세한 것은 `spark/README.md`. 실제 LLM·Spark 실기로는 시험하지 못했다.
- **그래픽**: 해질녘 조명·주변광 차폐·높이 안개(`game/src/render`), PBR 지면과 풀(`game/src/world`), 블렌더로 다시 만든 소품(`assets/models/env/*2.glb` 등). 환경 설정의 그래픽 품질로 무거운 효과를 끈다.
- **장비와 능력치**: 사냥터마다 다른 장비(투구·갑옷·장갑·장화·방패·망토·목걸이·반지 2칸, 일반·희귀·영웅·전설)가 떨어지고 발카르는 전설 1개를 확정으로 준다. 가방(I, 40칸)에서 아이템을 눌러 착용·강화·판매하고, 더 좋은 장비는 자동으로 갈아입는다. 방어력은 받는 피해를 100/(100+방어력)로 줄인다. 레벨업마다 포인트 3을 장비 창(C)에서 힘·민첩·체력·지혜에 나눈다.
- **상점과 강화**: 성채의 잡화상인 리나에게서 물약·강화 주문서를 사고(1개/10개) 안 쓰는 장비를 판다. 방어구·장신구도 "방어구 강화 주문서"로 강화한다(+3까지 실패 없음, +6부터는 실패 시 증발할 수 있다). 강화 창의 [자동 강화]를 켜면 잃을 위험이 없는 +6 전까지 이어서 강화한다.
- **필드**: 가끔 "광폭한 ○○"(정예, 보상 5~6배·장비 확정)이 나타나고, Lv.5부터는 적대 문파 [붉은까마귀]가 습격해 온다(물리치면 명성, 75초를 버티거나 성채로 들어가면 물러간다). 계정 캐릭터는 쓰러지면 현재 레벨 필요 경험치의 4%를 잃는다(체험 캐릭터는 벌점 없음).
- **도감과 편의**: 상단 [도감]은 종류별 처치 수(10·50·150마리, 보스 1·3·10회)마다 영구 보너스를 준다. 자동사냥 중 빨간 물약이 떨어지거나 가방이 가득 차면(팔 일반 장비가 있을 때) 마을에서 보급·판매하고 돌아온다. 환경 설정(톱니 단추)에서 음량·그래픽 품질·피해 숫자·이름표·자동 물약 기준·자동 착용·자동 보급을 바꾸며, 바꾼 설정은 이 기기에 남는다. [나가기]는 두 번 눌러야 나간다.
- **계정 캐릭터의 경제**: 물약·강화 주문서 드랍이 체험 모드보다 적고(상점에서 사서 쓴다), 내 레벨이 몬스터보다 6 이상 높으면 경험치가 줄며, 이야기를 마친 뒤 발카르는 쓰러뜨리고 30분이 지나야 다시 부를 수 있다.
- 검사: `node _work/v3/st/saga_test.mjs 4 25 --page=real.html`(이야기 통주), `node _work/systems_test.mjs`, `node _work/v3/st/modes_test.mjs --page=real.html`, `node _work/demo_smoke.mjs`, `python3 -m unittest discover -s spark/test`

## 다시 만들기
```bash
blender/rig_char.sh hero all            # 주인공: 가져오기→뼈대→가중치→장비→동작→검사·내보내기 (blender/current.blend)
blender/run_stage.sh s07_ad_render blender/scripts/s07_ad_render.py --open blender/current.blend -- hero   # 광고 렌더
python3 tools/verify_glb.py             # 블렌더 없이 GLB 만으로 숫자 검사(독립 구현)
cd game && node make_manifest.mjs && node pack_assets.mjs && node build.mjs   # 게임 빌드
node tools/shot.mjs "index.html?demo=1" _work/shots/demo.jpg --ready=__READY__ --shots=40 --every=5000   # 자동 모드 캡처
```
폴더: `input/`(주인공 원본) `blender/`(리깅 스크립트·작업 파일·렌더·검사 결과) `assets/`(모델·그림·소리·생성 기록) `game/`(소스) `dist/`(빌드 결과) `tools/`
